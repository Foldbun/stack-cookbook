# Security

Please report a security problem privately through GitHub: open the [Security tab](https://github.com/Foldbun/stack-cookbook/security) of this repository and choose **Report a vulnerability**. There is no email channel.

Do not include an API key, a request body with personal data or anything else secret in a report. If a key was exposed, revoke it in the Foldbun Stack console first.

This repository holds example code. For a problem in the Foldbun Stack API itself, report it the same way and say so; it is forwarded.
